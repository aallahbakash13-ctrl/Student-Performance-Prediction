\# 🎓 Student Performance Prediction Using Machine Learning



\## 📌 Project Overview

This project predicts students' exam scores using Machine Learning. It uses student academic and background information to estimate their expected exam performance.



The application is built using Python and Streamlit with an interactive dark-themed dashboard.



\## 🚀 Features

\- Student information input form

\- Exam score prediction using Linear Regression

\- Prediction history

\- Average predicted score

\- Interactive student performance dashboard

\- Exam score distribution visualization

\- Study hours vs exam score analysis

\- Attendance vs exam score analysis

\- Dark-themed user interface



\## 🛠️ Technologies Used

\- Python

\- Pandas

\- Scikit-learn

\- Streamlit

\- Matplotlib

\- Joblib

\- Jupyter Notebook

\## ⚙️ Installation



Clone the repository:



```bash

git clone https://github.com/aallahbakash13-ctrl/Student-Performance-Prediction.git

```



Install the required packages:



```bash

pip install streamlit pandas scikit-learn matplotlib joblib

```



\## ▶️ Run the Application



```bash

python -m streamlit run app.py

```



\## 📊 Machine Learning Model

Linear Regression is used to predict student exam scores based on academic and background features.
